Conecte seu projeto Firebase

Crie um projeto em console.firebase.google.com, adicione um app Web e copie os valores de firebaseConfig. Depois escolha um dos caminhos abaixo. São chaves públicas: quem protege os dados são as regras do Firestore.

Opção 1 — pelo painel do Cloudflare sem código

Em Workers & Pages › seu Worker › Settings › Variables and Secrets, crie estas variáveis e implante de novo: 

FIREBASE_API_KEY      = AIza...
FIREBASE_PROJECT_ID   = seu-projeto
FIREBASE_APP_ID       = 1:000000000000:web:abc123

Opcionais: FIREBASE_AUTH_DOMAIN, FIREBASE_STORAGE_BUCKET e FIREBASE_MESSAGING_SENDER_ID — os dois primeiros são deduzidos do FIREBASE_PROJECT_ID quando ausentes.

Opção 2 — no repositório

Preencha public/js/config.js e faça o commit:

export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "seu-projeto.firebaseapp.com",
  projectId: "seu-projeto",
  storageBucket: "seu-projeto.appspot.com",
  messagingSenderId: "000000000000",
  appId: "1:000000000000:web:abc123"
};

Depois, em Firebase › Authentication: habilite E-mail/senha e Google, e adicione este domínio em Settings › Authorized domains. Passo a passo completo no README.md.
